## Pertemuan 4 — Design token halaman profil

* Halaman: Ride & Care
* Berkas gaya: `tokens.css`, `base.css`, `layout.css`, `komponen.css`, `tema.css`
* Warna utama: `#1D3A8C`
* Warna utama dipilih karena memberikan tampilan yang bersih dan sesuai dengan tema halaman profil motor.
* Token digunakan agar perubahan warna, jarak, ukuran teks, border, dan komponen dapat dilakukan secara konsisten.

### Token yang saya tetapkan

| Token             | Nilai     | Untuk apa             |
| ----------------- | --------- | --------------------- |
| `--color-primary` | `#1D3A8C` | tombol, tautan, judul |
| `--color-fg`      | `#0F172A` | teks utama            |
| `--color-bg`      | `#F8FAFC` | latar halaman         |
| `--color-surface` | `#FFFFFF` | kartu dan form        |
| `--color-border`  | `#D1D5DB` | garis pembatas        |
| `--radius-md`     | `0.5rem`  | kartu dan tombol      |
| `--space-4`       | `1rem`    | jarak standar         |

Kriteria selesai saya adalah ketika `--color-primary` diubah pada satu baris di `tokens.css`, maka warna tombol, tautan, judul, dan fokus halaman ikut berubah.
